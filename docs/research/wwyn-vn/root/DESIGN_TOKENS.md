# WWYN Design Tokens

## Colors
- **Primary / Pure Black**: `#000000` / `rgb(0, 0, 0)`
- **Body Text Dark**: `#212529` / `rgb(33, 37, 41)`
- **Header Background**: `rgba(26, 26, 26, 0.3)`
- **Header Scrolled Background**: `rgba(20, 20, 20, 0.95)`
- **Pure White**: `#ffffff` / `rgb(255, 255, 255)`
- **Subtle Border Grey**: `rgba(26, 26, 26, 0.2)`
- **Footer Text Link**: `rgb(33, 37, 41)` / `#212529`
- **Muted Slogan Text**: `#000000` / `rgb(0, 0, 0)`
- **Accent Underline**: `rgb(0, 0, 0)`

## Typography
- **Primary Font Family**: `"Helvetica Neue", Helvetica, Arial, sans-serif`
- **Headings & Menu**:
  - Main Navigation: `12px`, weight `500`, uppercase, line-height `54px`
  - Mega Menu Titles: `16px`, weight `500`, line-height `25px`
  - CTA Button: `16px`, weight `700`, uppercase, line-height `25px`
  - Footer Titles: `13px`, weight `700`, uppercase, line-height `16.25px`
  - Footer Links: `13px`, weight `400`, line-height `19.5px`
  - Footer Store Info: `13px`, weight `400`, line-height `25px`
  - Slogan / Disclaimer: `11px`, weight `400`, line-height `14.3px`
  - Copyright: `12px`, weight `400`
  - Location/Delivery Labels: `11px` - `12px`, weight `500`, uppercase

## Spacing & Dimensions
- Desktop Header Height: `54px`
- Desktop Center Container: `max-width: 1440px`, padding `0 30px` (or `max-width: 1366px`)
- Footer Top Padding: `70px 0px` (desktop), `30px 0px` (mobile)
- Footer Bottom Height: `58px` (desktop), `106px` (mobile)
- CTA Button: width `200px`, height `48px`, border `2px solid white`
- Menu Icon Size: `20px x 20px`
- Social Icon Size: `24px x 24px`

## Breakpoints
- Desktop: `> 1024px`
- Mobile: `<= 1023px` (specifically tested at `390px` mobile viewport)
